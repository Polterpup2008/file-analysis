# GUI validation checklist

The native interface needs an interactive Windows desktop. The GUI driver in `tests/gui_smoke.mjs` is separate from CTest and uses the Computer Use API when that runtime is available.

1. Open a plain image, an image with generation settings, and a malformed fixture generated by `tests/make_fixtures.py`.
2. Check that Simple is the default and highlights useful evidence, with warnings visible and missing information labeled honestly.
3. Switch to Detailed and inspect Metadata, Structure, Hex and Provenance. Switch back without rescanning.
4. Filter and search findings, select rows, and check readable details and Copy.
5. Export a full report from Simple; confirm that raw fields and blocks are retained and local-path redaction is applied when selected.
6. Resize the window and check text clipping, wrapping, scrolling, keyboard focus and control visibility.

The 0.3.0 release passed all three local automated suites. Simple was visually checked on a real Gemini PNG. The final automated view-switch check was incomplete; this checklist describes additional verification to perform, not checks claimed as completed.
