# File Analysis 1.0 acceptance plan

The objective is the original native, offline C++20 application plus the agreed 1.0 roadmap. A version number alone is not completion. Unsupported formats, parsers and identity conclusions must remain explicit.

- [x] Baseline: Win32 Simple/Detailed views, background scans/cancellation, signatures/hashes/filesystem data, ExifTool evidence, generation recognizers and C2PA claims/integrity/trust/history (0.5 baseline).
- [x] Recorded camera/lens/settings/time/GPS, including conflict and missing/unavailable states (0.4).
- [x] Origin signals, selected-field privacy review and share-summary exports retaining full evidence (0.5).
- [x] Recover/view supported embedded previews in a native window and export exact recovered bytes with sources/hashes and payload/pixel limits (0.6 checkpoint; final title and exact dialog extraction verified).
- [x] Search the analyzed batch/folder, including device/software/GPS, and navigate matches back to files (0.7 checkpoint; actual Find and source navigation verified).
- [x] Readable two-file added/removed/changed evidence in Simple/Detailed, retaining duplicate/raw fields and full exports (0.8 checkpoint; actual comparison and view switching verified).
- [x] Resolve observed GUI issues; verify actual open/filter/search/copy/export/preview/comparison/batch/cancellation paths and supported sizes.
- [x] Verify malformed/huge/Unicode/no-metadata/resource/conflict/duplicate inputs, parser bounds, unchanged originals and new-destination protection (ten suites / 440 local checks, plus private Gemini regression).
- [x] Audit format claims against representative fixtures, separating recognition, metadata and native structure validation (82 format checks; see FORMAT-COVERAGE.md).
- [x] Repeatable bootstrap/build/test/packaging and automated GitHub release builds with pinned dependencies/notices and private commit email (local package plus hosted Windows build; no bit-identical toolchain claim).
- [ ] Complete a requirement/evidence audit, run the final executable, publish exact sources/executable/checksums and verify the public download.

Recheck every original specification area: platform/UI; signature/hash/filesystem analysis; metadata provenance/duplicates/raw values; generation recognizers and honest absence; C2PA claims/integrity/trust/history; structure/hex/extraction; comparison; performance/cancellation/Unicode; exports/privacy; real/generated/malformed/batch/GUI tests; actual executable and build instructions. Existing documented decoder/recognizer limits must be audited rather than hidden by tests or wording. No inferred AI account/model/physical identity, online lookup, certificate purchase or security-setting change is assumed.
