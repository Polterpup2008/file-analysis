# 1.0 requirement/evidence audit

Release status: **1.0.0 published and verified on 2026-10-23**. [Download the portable Windows release](https://github.com/Polterpup2008/file-analysis/releases/tag/v1.0.0). Functional acceptance passed on Windows x64; public release 0.5 was the published baseline before this work.

Current local code passes ten suites / 440 assertions, including new checks that reader errors cannot establish absence of camera or preview metadata. An optional regression on the original private Gemini PNG passes 52 provenance assertions and reports 344 chunks, four display groups, two manifests and zero errors; the private input is not published. The owned 0.8 test process with two generated files used 23.6 MiB working set / 4 MiB private memory and zero measured CPU time over a 5.15-second idle sample; this is a small-input observation, not a worst-case benchmark.

[PR #3](https://github.com/Polterpup2008/file-analysis/pull/3) carries the release. [Hosted Windows run 39904722147](https://github.com/Polterpup2008/file-analysis/actions/runs/39904722147) passed a fresh pinned bootstrap, build, ten suites / 438 assertions and ZIP/checksum generation for public head 97bf3c4, source tree equal to local fe77196. The two optional local Canon assertions explain the local total of 440. Artifact digests matched GitHub's metadata; inner ZIP checksums, every source file and BUILD.txt identity were verified independently. [Final hosted run 39908209913](https://github.com/Polterpup2008/file-analysis/actions/runs/39908209913) passed all ten suites / 438 assertions at head 8bc6e8b, including the GUI newline fix. PR #3 was merged. Tag v1.0.0 and BUILD.txt both identify canonical main commit 31924c29b7455ef57251f1a65c23318709312d32, whose tree matches the tested release branch.

Actual desktop checks are recorded in GUI-TESTING.md: portable preview/extraction and batch navigation, followed by the revised executable's readable details, comparison in both views, minimum-size wrapping, clipboard, six-file batch, three full export formats, generation export, cancellation and close during work. No source file was modified by analysis.
