# 1.0 requirement/evidence audit

Functional acceptance: **passed on Windows x64**. Publication remains a separate delivery gate recorded on the GitHub release. Public release 0.5 was the last published download at the start of this audit.

Current local code passes ten suites / 440 assertions, including new checks that reader errors cannot establish absence of camera or preview metadata. The two optional local Canon assertions explain the local total of 440. The final GUI-only newline fix and acceptance documentation require a green final hosted head before merging.

Actual desktop checks are recorded in GUI-TESTING.md: portable preview/extraction and batch navigation, followed by the revised executable's readable details, comparison in both views, minimum-size wrapping, clipboard, six-file batch, three full export formats, generation export, cancellation and close during work.
